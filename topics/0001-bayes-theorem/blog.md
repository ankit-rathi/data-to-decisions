# Bayes Theorem

Blog draft to be created from the research and blog prompt.

## Suggested central example

Fraud detection:
- 1% fraud rate
- 90% detection rate
- 5% false-positive rate
- 10,000 transactions
- 90 true positives
- 495 false positives
- Posterior ≈ 15.4%

Core mental model:

Prior → Evidence → Update → Posterior → Validate → Decide → Act → Learn
