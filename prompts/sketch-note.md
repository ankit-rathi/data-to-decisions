# Sketch Note Prompt

Topic: {{TOPIC}}

Source blog / understanding: {{BLOG}}

Create a single handwritten-style visual sketch note in slide aspect ratio (16:9).

Purpose:
- Give the viewer the complete mental model quickly.
- Connect theory to intuition, practice, reality and decision-making.
- Work for both students and Data/AI professionals.

Prioritize:
- One central idea
- A clear visual flow
- One memorable example
- Key equations only when genuinely useful
- Practical/industry insight
- Final takeaway

Use minimal wording. Do not turn the sketch note into a miniature blog.

Style:
- Handwritten
- Clean
- Human
- White/light paper background
- Simple boxes, arrows, symbols and diagrams
- Legible at slide size
- Visually balanced
