# Reel / YouTube Short Prompt

Topic: {{TOPIC}}

Source sketch note / blog: {{CONTENT}}

Create a natural 60–120 second spoken script explaining the sketch note.

The script should sound like an experienced practitioner teaching a useful idea, not a formal lecture.

Structure:

1. Hook — why should I care?
2. Core idea
3. Walk through the sketch note
4. One strong example / aha moment
5. Practical industry implication
6. Memorable closing insight

Use conversational language.

Do not try to cover every detail from the blog. The goal is understanding, not completeness.
