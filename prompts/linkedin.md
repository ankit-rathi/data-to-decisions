# LinkedIn Prompt

Topic: {{TOPIC}}

Source sketch note / blog: {{CONTENT}}

Write a concise LinkedIn post that explains the main insight in the sketch note.

It should sound like an experienced Data/AI practitioner sharing something they found useful — not like AI-generated marketing copy.

Requirements:

- Start with a surprising question, observation, paradox or practical example.
- Explain the key insight clearly.
- Use minimal wording.
- Do not reproduce the entire blog.
- Let the sketch note carry the visual detail.
- Connect theory to practical Data/AI reality.
- Avoid artificial motivational language.
- Avoid excessive emojis.
- End with one memorable takeaway.

Keep it concise and natural.
