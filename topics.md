# General Rule

When a topic becomes active:

1. Define the question.
2. Decide whether it is based on research, experience, or both.
3. Identify the appropriate authority level.
4. Research / experiment.
5. Distil one insight.
6. Make one sketch.
7. Create the Short.
8. Add deeper formats only if justified.
9. Capture feedback.
10. Identify the next question.
